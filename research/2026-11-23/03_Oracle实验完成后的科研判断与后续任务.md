# Oracle 实验完成后的科研判断与下一步研究任务

**评审日期**：2026-11-23。**证据来源**：本仓库 `literature/quantile_treatment_rules/oracle_20261123/STATISTICAL_REVIEW.md`；其依据的原始结果 ZIP 已分片归档在 `original/`。**证据级别**：本文件根据已提交统计评审逐项进行推理与交叉检查，不代表重新执行 500 万测试患者的完整 Oracle 仿真，也不代表已经进入有限样本估计实验。

## 一、之前路线图的 Gate S 状态修正

**结论：Gate S 的「已有真实规则差异」子任务已完成；Gate S 的「分位数保护为何比可替代保护更有独特价值」仍未完成。不得重新安排一次同义 Oracle 实验。**

- 5 类机制，每类 200 次重复、每次 5,000 个测试协变量记录；全体 5,000,000 条记录，同一次重复下配对共用患者。
- 主要阈值：`p_all=0.50`、`p_1=0.10`、`L=36` 月、`δ=3` 月。
- `aligned` 与 `heterogeneous`：Q–Q 和 Zhou2024 完全一致；异质性不意味着两种价值准则必然不同。
- `PH_tradeoff`：Q–Q 与 Zhou2024 改判 3.430%；`time_cross` 改判 34.991%；外部指数机制 40.489% 改判，但主要涉及顶端分位数饱和与原因构成改变。
- `time_cross` 有 54.065% 的患者在所检查分位水平网格内出现两治疗的**严格内点分位数排序翻转**。典型患者 `Z=(0,0)`，`p_1=0.10` 时两治疗 Q1=7.36/8.23 月，`p_1=0.15` 时 Q1=11.69/11.03 月；证明非 PH 的曲线交叉能改变最优处理方向（限定在预设模型与阈值扫描下）。
- Q–Q 对总体分位数预算的零违反率为 Oracle 规则的**定义性**属性，绝非估计稳定性证据。

## 二、对已有结果的量化科研评审

### 2.1 Q–Q 对仅 Qall 的真实增量：这是规则第二层的作用

| 机制 | 改判比例 | 全人群平均 Δ重点Q（月） | 全人群平均 Δ总体Q（月） | 全人群平均 ΔRMET（月） | 改判人群的 ΔCIF1(36月) / ΔCIF2(36月) |
|---|---:|---:|---:|---:|---|
| PH_tradeoff | 28.081% | +2.805 | −0.368 | −0.163 | −16.346 / +18.481 个百分点 |
| time_cross | 21.602% | +0.139 | −0.314 | −0.066 | +15.195 / −10.838 个百分点 |

上述全人群差是改判比例乘以改判者均值，和 `STATISTICAL_REVIEW.md` 的全人群汇总对得上。**重要：第一行的 CIF 改善伴随竞争 CIF 恶化；第二行即使 Q1 时间变晚、期末重点 CIF 却明显上升**。二者都不应解释为无条件临床获益。

### 2.2 Q–Q 相对 Zhou2024 的方向不稳定

- `PH_tradeoff`：Q–Q 全体平均 Q1 **10.701** vs Zhou **11.298** 月；Q–Q 并非对所有机制的 Q1 都更好。
- `time_cross`：Q–Q 的 Q1 **8.632** vs Zhou **8.276** 月，增加 **0.356** 月，但三年重点 CIF **38.633%** vs **34.478%**；风险时间偏好与 36 月发病概率偏好发生冲突。
- `Zhou_exp`：Q–Q 全体重点 Q 比 Zhou 高约 **12.663** 月，而其中 **12.254** 月（96.77%）来自 Q–Q 取到 `L` 的上限状态。竞争 CIF36 **89.539%**，不能将其作为临床价值最强证据。该机制的原生随访窗口为 2 年，而本实验延长至 3 年，不能称作原论文三年设置的完整复现。

### 2.3 创新性最重要的“负面证据”

以相近「两个候选治疗都合格」的患者比例校准 RMET–Q1 第一层保护后，在 `PH_tradeoff` 和 `time_cross`，Q–Q 与 RMET–Q1 的不一致比例只有 **2.511%** 和 **2.097%**。因此：
- 尚**不能**证明总体分位数保护在临床决策上显著优于总体 RMET 保护；
- 现有实验证明的是**重点原因 CIF 分位数阈值有信息**、**两准则会改判**，并未证明**总体分位数约束不可替代**；
- 匹配候选比例并不等价于两个约束具有相同风险代价，下一步仍须比较各自对个体条件分布的保护强弱。

## 三、将论文核心科学问题进一步缩窄

要避免「仅将已有 Zhou 两层规则中的数值指标替换成另一数值指标」，应明确拟解释的患者偏好：

> 在先验愿意以某个最大可接受总体首次事件阈值时间损失来换取重点事件某个累计风险阈值达到时间的患者中，何时 Q–Q 能提供积分/RMET 和固定终点 CIF 价值函数**没有直接表达的时间局部信息**？该新增信息是否足以影响推荐、且不只是原因间风险转移？

将风险水平 `p_1` 事先解释为临床可接受的风险界限，不能从模拟中搜索哪一个 `p` 使 Q–Q 最好后再倒写临床原因。

## 四、实验研究下一阶段：只做补缺，不重复 Oracle

### Gate S 补缺任务（优先级 P0）

1. **原有 Oracle 结果的「候选差异来源」分解**：在关键机制中，逐患者比较 Q–Q 与 RMET–Q1：第一层候选集不一致率、第二层重点排序差异、顶端截断、可达与不可达子群。必须报告*相同候选比例下仅 2% 左右的规则差异*。
2. **完全内点、预设阈值分析**：将 `F_1^a(L)≥p_1`、`F_{all}^a(L)≥p_{all}` 的真实支持分层，用原始实验所含个体记录复算 Q–Q vs Zhou 的改判比例与真实 Q1、RMET、F1/F2，避免把大量不可达当成方法优势。预设阈值扫描要展示全部 p 网格，而非事后挑优势 p。
3. **临床偏好一致性审计**：在 `time_cross` 风险水平翻转子群报告 `F_1(t)` 随时间路径、`F_1(36)`、`F_2(36)`、RMET，标注“早期阈值收益与期末风险损失”并明确适用的患者价值判断。
4. **Gate S 判定**：如果在完全内点且竞争事件代价可解释的预设群体中仍有稳定改判，再将科学目标视为充分；如仅靠顶端饱和或转移原因，需收窄研究目标，不可继续声称总体收益。

### Gate E：有限样本估计（优先级 P1）

Gate S 的补缺与临床目标确定后，**固定上述 Oracle DGP/threshold/test population**，从同一份带右删失数据中比较：
- 原因别 Cox–Breslow baseline；
- 预先确定自由度的时变原因别模型；
- 柔性 CIF 估计（例如 CR-RSF-CIF）；
- 直接 Peng–Fine 重点分位数与独立总体估计的联合混合路线（有可达、右删失、相容性与失败率说明）。

配对报告：条件 Qall/Q1 的 MAE、`F_1(L)` 与 `F_2(L)` 的拟合误差、保护边界误判、候选误判、处方误判、真实 Q1 遗憾/预算超额、估计失败率。重要：`Q_1` 的估计误差虽小，却可能因总体保护边界误判导致更高实际 regret。

### Gate T：理论（优先级 P2）

- 保留分位数统一误差条件下的 `δ+2e` 预算上界，但注明其一般 plug-in 性质，不可作为唯一创新。
- 围绕 `H_δ(z)=||D_{all}(z)|-δ|` 的边界误判概率与顶端不可达分层构建更针对性的结果；对离散协变量的正边界质量给出反例。
- 区分真值下 Q–Q 规则的可行性（构造保证）与有限样本估计的违反率；不给尚未证明的治疗策略效果贴“保证”标签。

### Gate R：真实数据（优先级 P3）

在 LK16-02 和 IST 上，优先报告指定 p 下可达比例、推荐治疗1比例、按患者协变量分层、两原因 CIF 12/36 月、3 年 RMET、条件/边际价值的区分与独立交叉拟合不确定性。模型预测的未用药条件结局不等于观察到的治疗因果收益。

## 五、下一步可执行的最小验收标准

新增一个**不是**重新跑全规模 Oracle 的分析脚本，以现有归档中的个体级结果为输入：输出 `Q–Q vs RMET–Q1` 候选差异的分解、真实可达子群结果、`time_cross` 的完整阈值路径三张图表。若现有 CSV 缺必需逐患者字段，则新增一次**定向** Oracle 运行补足，不再重复五机制全部结果。

这一关结束后，冻结新的估计器比较协议，进入带删失的 Gate E。若 Gate S 临床解释无法成立，应调整论文问题而非为扩大差异而调整模拟系数。
