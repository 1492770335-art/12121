# 竞争风险条件分位数受约束个体化治疗规则：科研路线图（2026-11-23）

**文档性质**：研究决策框架/预注册草案，非实验结果。**前提**：已完成六篇核心分位数论文精读，已有 Cox-CIF 工作模型与若干模拟、LK16-02/IST 应用结果。**优先级**：先确认决策准则本身的科学意义，再选估计器；原则上不为制造胜出而事后调节 DGP。

## 核心判断与研究问题

必须回答五个可证伪问题：

1. **R1（意义）**：在一般竞争风险 DGP 的 oracle 真分布下，患者条件 CIF 分位数目标是否能提供 RMET、固定时点 CIF、CIF 积分等既有目标未能直接表达的风险时间偏好？在哪些患者和概率阈值下会改变处方？不可达截断是否是主要来源？
2. **R2（安全）**：以总体首次事件分位数为保护，能防止重点事件分位数因竞争事件增加而被动改善吗？是否需额外的原因2风险约束/效用检验？保护的是*一个指定概率水平的时间*，绝非全时域生存或所有安全终点。
3. **R3（识别）**：从 `(X,Δ,J,A,Z)` 能否在条件可交换性、治疗/删失正值性、可达与模型支持内识别两个治疗下的 `F_j^a` 以及条件分位数？在 `F_j^a(L)<p_j` 时必须区分“不可达分位数”与“被定义为 L 的截断分数”。
4. **R4（估计）**：固定决策准则后，Cox-Breslow、时变原因别、柔性 CIF、Peng–Fine 直接条件分位数哪个更准确可靠？同时评价 `Q_all` 与 `Q_1`、可达率、联合相容性、候选边界错误，不可用结果较好的模型事后覆盖。
5. **R5（理论/临床）**：给出可检验/可解释的保护超额损失、边界稳定与重点价值差异界；在真实资料中按协变量分层报告改判比例、完整事件结局，避免以模型内预测改善冒充已识别的治疗效果。

## 0. 研究定位冻结：避免与文献冲突

- 文献优先级（详见同目录 `01_创新性冲突与现有研究核查.md`）：Christina Zhou 2024 两阶段竞争风险规则；Jie Zhou 2021 约束型竞争风险；Peng–Fine 2009 CIF 分位数；Lei–Qu 2026 约束分位数；Fang–Chen–Liu 2026 分布先行 plug-in。
- 本文不是“两次给药”的 dynamic treatment regime，而是**单次基线治疗的两层（先保护再择优）决策准则**。题目如保留“两阶段”需在摘要/引言作术语澄清。
- 独立创新候选：逐患者相对最佳总体首次事件分位数的时间容忍预算、原因别 CIF 分位数目标、它们在竞争风险中的联合临床解释/可达性/边界稳定/估计决策耦合。**创新性有待 oracle + end-to-end 证据支持**。
- 分清 conditional `Q_j^a(p|Z=z)`、policy marginal `Q_p(T^{d(Z)})`、以及 `E_Z Q_j^{d(Z)}(p|Z)`。这三者不是相同 estimand。
- 分清 `Q_{all}` 保护和 `RMET` / `F_2(L)` 保护。不能声称前者保证后两者。

## 1. 第一优先研究（Gate S：科学目标/准则的 Oracle 验证）

**先不引入任何估计误差**，用已知真值的通用两原因生存数据生成机制构造 CIF 与 `Q_{all,L},Q_{1,L}`，完整运行各规则。拟预注册：
- 至少三个中立结构：PH 同向、PH 冲突、非 PH 治疗×时间交互；可再包含弱/强异质性但要明示这是科学性敏感性而非择优参数。
- 初始 `Z_1~U(-1,1),Z_2~Bernoulli(0.5)`；治疗1/0可交换，两个原因都允许 `A×Z`，但不手动指定某方法胜出的患者区间。
- 随访窗 `L=36月`；临床共同时点 `t_0=12月`；原论文 `δ=3月` 作为默认工作值；`p_{all},p_1` 的选择应先报告校准公式与分布，不得事后使 Q–Q 获胜。**为比较不同阈值偏好可以增加预先指定的 p 网格，但必须同时保留全部阈值结果。**
- 主对照应至少包含：(a) 本文 Q_all–Q_1 两层规则；(b) Christina Zhou 原生两层 RMET/积分 CIF 规则；(c) Jie Zhou 原生受约束 CIF 目标（明确其边际可行性，与逐人比较不完全同类）；(d) 无约束 RMET 最大；(e) 重点固定时点 CIF 最小。每个规则均按**作者原生定义**运行，不能替换其阶段准则以利于本文。
- 所有政策使用同一套 oracle 真 CIF，报告：治疗1比例、政策间不一致率、条件 `Q_{all,L}` / `Q_{1,L}` 的人群平均、3年 RMET、`F_1(t_0),F_2(t_0),F_1(L),F_2(L)`、患者总体预算违反率与超额幅度、目标分位数可达率与双药不可达比率。
- **分层**：预定义 `Z_1` 四分位×`Z_2`；同时分解总改判率为候选集差异/候选内重点排序差异、可达/不可达造成的选择，报告改判患者的条件结局差与全人群结局差。
- **同一患者纵向阈值轨迹**：固定几组事先确定的 z，展示不同 `p_1` 的重点分位数及治疗翻转点，并核对是否来自 CIF 曲线交叉、总体筛选或截断并列。
- **反证例**：固定总风险、两原因交换强度（如 `λ_{all}=0.3/y`，`(λ_1,λ_2)=(0.2,0.1)` vs `(0.1,0.2)`），两药有相同总体生存及 RMET，但目标分位数差来自原因构成改变，须披露原因2代价。
- 输出三张主表：完整政策表 / 患者改判异质性表 / p 轨迹与 CIF 可达性图；另外固定**阴性场景**展示规则没有明显新增信息的情形。

**Gate S 结果标准**：必须识别至少一个*事先界定、具有临床解释且可重复*的患者层面差异机制，并同时展示总体/竞争终点代价；若优势只来自平台不可达或原因2明显恶化，则不以“统计改判”为创新性证明，转向解释适用边界或修订 estimand。

## 2. 第二优先（Gate E：同一准则下估计器比较）

固定 Gate S 的真 DGP、样本 `n=500/1000/2000`、删失20%/45%、训练/独立测试拆分与 Monte Carlo 种子；可先小 pilot 检查实现，再冻结主模拟次数（建议 >=200 对/格，以置信区间精度而非追求显著性决定）。

统一接口 `fit(Data)->{F_1^a(t|z),F_2^a(t|z), Q_{all,L}^a,Q_{1,L}^a,flag_reachable}`：
1. 共享基线原因别 Cox-Breslow（**基准**）。
2. 允许时间×治疗项的原因别模型（预先固定自由度/交互）。
3. 柔性原因 CIF 方法（如 CR-RSF-CIF；诊断模型依赖与方差）。
4. Peng–Fine 型直接 `Q_1(p|z,a)` + 独立的总体分位数估计器（**混合路线**，不是现成的完整联合方法）。确保删失 IPCW、正值性、治疗交互、可达性和预测单调；**不得虚构原因1、原因2两条独立估计 CIF 的联合相容性**。

主要指标：`MAE(Q_all)`, `MAE(Q_1)`, 分位数可达状态误判率、候选集误判率、推荐处方误判率、边界邻域 MAE、模型失败率、政策真实 regret（对 oracle Q–Q），以及两原因 CIF 联合合法性。配对差值报告 MCSE/95% CI；失败和不可达不得剔除后只报告“成功者”。

**Gate E 标准**：明确何时基准 Cox 足够、何时 PH 违背导致显著决策错误、何时直接模型也存在可达性/方差/相容性问题。若模型差异很小，不强行将新估计器包装为主要贡献。

## 3. 第三优先（Gate T：仅证明必要且针对性的理论）

1. **识别命题**：给定治疗一致性、无混杂、治疗/删失正值性，证明 `F_j^a(t|z)` 可识别；明确可识别的条件支持、零密度与不可达边界。
2. **估计命题**：对选定估计器给出一致性（或诚实界定采用现有理论）；若 `F'(q)≥m>0`，反演误差可由 CIF 误差除以 m 控制，`F'(q)≈0` 或端点贴近 L 时不能声称全体统一速率。
3. **预算保护命题**：`sup_{z,a}|Qhat_all-Q_all|≤e` 则估计规则 `M_all-Q_all(dhat)≤δ+2e`，并截断到 `L`。清楚标注此为基础 plug-in 界，**不是深层原创**。
4. **候选稳定命题**：设 `H_δ(z)=||Q_all^1-Q_all^0|-δ|`。当 `H_δ(z)>2e`（并妥善处理平局）两候选集相同。报告 `P(H_δ≤2e)`，不得把“超额幅度收敛”混同“违反概率收敛”。
5. **重点价值损失**：区分候选集相同/不同引起的决策误差，给出最小而可解释的条件界；新理论必须与 Lei–Qu/Fang 的通用风险/regret 界比较，而非重述同样 plug-in 三角不等式。
6. **边界反例**：离散 Z 或分位数顶端并列时，`P(H_δ=0)>0` 可违反 margin 假设；这决定了违反概率或规则稳定性并不能从基础一致性自动推出。

**Gate T 标准**：不为了凑命题数量而扩大理论；只对 Gate S/E 发现的重要问题建立证明。

## 4. 第四优先（Gate R：真实数据与临床可解释性）

- LK16-02 和 IST 先做事件定义/时间单位/首发互斥性核验；原始事件是否能解释为治疗权衡，以及严重程度是否具有可比性。
- 报告治疗1总体推荐比例、预设风险组条件推荐比例、总体分位数、原因1分位数、3年 RMET、两原因 12/36 月 CIF、可达率和样本外不确定性。
- 真实数据**没有逐患者的未接受治疗的真值**；模型预测出的“两方案潜在结果差”不是已观察疗效。应通过独立交叉拟合与适当 IPCW/IPTW / AIPW 价值评价来估计政策的边际结果，并报告识别假设、概率权重波动、有效样本量和区间；不可将模型内汇总误当作独立评价。
- 检验估计风险：治疗倾向极端、删失与中心效应、时间非 PH、概率阈值不可达、模型跨院外推、关键因果协变量缺失。
- 在“保护阈值相同的治疗选择”等有医学意义的群体内，报告原因构成与临床代价；**不能仅凭几天或数月阈值时间提高便断言临床上净获益**。
- 若真实资料主要表现为 `Q_1=L` 的堆积，清楚报告 36 月内事件发生及 CIF 差，并考虑把分位数改为限定于可达支持下的研究目标；这属于研究定位调整，需对原结果作完整重估而非选择性改写。

## 5. 论文可发表性 Gate 与退出条件

| Gate | 研究问题 | 必需成果 | 遇到阴性结果时的处置 |
|---|---|---|---|
| S: 科学目标 | 分位数规则是否在同一真 CIF 下提供新增临床可解释信息？ | Oracle 主表、政策差异分解、反证例及可达性审计 | 收窄为指标适用性研究，勿声称普遍优效 |
| E: 估计 | 有限样本能否稳定复现 oracle 推荐？ | 估计器交叉、MAE/候选误判/失败率、配对 CI | Cox 保留基准，承认估计受限 |
| T: 理论 | 哪些可识别、保护、稳定性性质是本题独有？ | 精简定理、margin/可达性假设、反例 | 保留应用/数值贡献，不制造“新定理” |
| R: 真实数据 | 是否临床可解释且样本外可支持？ | 多终点、分组、外部/交叉拟合验证 | 不扩大临床推广结论 |

## 6. 预注册科研纪律

- 在看完新方法的主模拟结果之前冻结 DGP、`p`、`δ`、`t_0`、`L`、主估计量、主要比较与图表。
- 对照方法必须各自**原生**实现，不修改他人的目标函数为己用；特别注意 Jie Zhou (2021) 的**人群边际约束**与本文**患者条件预算**不能写成同一种约束。
- 先定临床情景与效用，再选数据；既报告优于对照的情形，也报告相同与劣于对照的情形。
- 每个实验保存完整 DGP 参数、随机数种子、源代码 commit、失败运行、生成数据协议、主表与图、环境说明。
- 结果需区分真值 Oracle、工作模型内预测、IPW/AIPW 验证、真实观察结果；不将不同证据等级混为“临床优势”。
- 论文可行性最小集合：**一套主数据生成框架 + 三类科学机制 + 两张核心比较主表 + 一张异质性表 + 一套误差/稳定性理论 + 一份真实数据有审计的应用**。不以堆砌敏感性分析取代研究问题。

## 7. 推荐执行顺序及产物

1. 完成文献差异/术语/estimand 审计并冻结研究目标（本文件）。
2. **先运行 Gate S Oracle 对比**，只比较规则：先验证意义，不涉及 Cox 是否有效。
3. Gate S 有明确可解释信号后再运行 Gate E 估计器对比，原论文共享基线 Cox 作为 baseline 而非正确答案。
4. 根据 S/E 的失败方式选取 Gate T 的理论命题，不提前编造高层新颖性。
5. 在 LK16-02/IST 中执行 Gate R，优先多终点和样本外评价。
6. 全文重写：问题定义→与先行约束型竞争风险 ITR 的区别→Oracle 意义→估计器→理论→完整模拟→真实数据→限制。
