# 阶段四：Zhou 式有限维索引决策模型（拟议替代方案）

用户指出可以调整决策结构，不应预设必须保留原插入式规则。以 Yu Zhou et al. (2023 JASA, DOI 10.1080/01621459.2022.2068420; arXiv:2204.04052, Sec 2.2, 3.1) 为主要范式：先定义有限维候选规则类，再定义最优决策参数，再构造其估计量与渐近理论。

## 建议优先研究的模型
B_j(z)=q_j(z,1)-q_j(z,0)，delta>0。取预先固定特征向量 h(z)（可含截距、交互、样条），归一化决策系数 beta（例如单位范数、识别唯一的尺度）。定义 d_{beta,delta}(z)=1 if B0>delta; 0 if B0< -delta; I(h(z)^T beta>0) if |B0|<=delta。总体保护门控保证每个候选规则真实可行。V_delta(beta)=E[q1(Z,d_{beta,delta}(Z))]，beta*=argmax_{beta in B} V_delta(beta)。若真实 B1 符号在双候选区域可由 h^T beta 表示（B1=0 时任一均最优），则类中最优值等于原 oracle；否则是受限最优而非原 oracle。

可将与 beta 无关部分消去：beta*=argmax E[I(|B0|<=delta) B1(Z) I(h(Z)^T beta>0)]。原因别 Cox+Breslow+CIF 反演估计 B0,B1。样本决策参数 argmax n^{-1} sum I(|hat B0_i|<=delta) hat B1_i I(h_i^T beta>0)。最终 d_hat 以估计门控和估计 beta 推荐。可使用交叉拟合，但不是理论充分条件。估计门控不保证有限样本真实可行。若直接在固定全局线性规则类上施加逐点约束，可能无可行解，故优先采用门控结构。

## 理论目标
研究 beta_hat 的识别、相合、收敛阶及极限分布，以及最优值（包括非唯一时）。与 Zhou 不同：样本准则为 Cox 拟合对比、门控依赖估计的总体分位数。其局部经验过程不一定有 Zhou 的 n^-1/2 r^1/2 阶；若可正确表示逐点最优符号，真实权重 B1 在规则边界为零时局部波动可能更小。需要同时分析 Cox 估计、随机门控、经验协变量分布以及总体曲率，不可直接宣布 cube-root 或 root-n。可先在真实门控和真实对比下研究局部准则，再逐个加入 nuisance。尺度归一化不足以保证唯一识别；需另验证人口目标唯一极大与非退化曲率。

## 决策
这是新估计方法的候选结构，非仅改符号。原 Cox 插入式方法保留为无约束规则类基准；现有模拟与实证结果不得自动移植，若采用本路线须重新拟合。QNB 与 R_Q 继续只用于统一外部评价，Oracle 参照必须明确是原全类 oracle 还是受限 oracle。未修改正式程序/稿件，未运行实验，未证明新参数的具体渐近率。
