# N2 Native Benchmark — 预先冻结的首轮竞争风险分位数估计实验（v0.1）

建立：2026-11-23。**本文件先入库，再执行后续数据生成和方法比较**。首次小规模运行属于兼容性与可复现性验证（smoke/pilot），不是充分把握度的方法优劣检验。原有 N1、N2-3 资料不改动。

## 研究问题

对相同右删失、两治疗、两个互斥首次事件数据，直接竞争风险分位数回归（Peng–Fine / `cmprskQR`）与条件 CIF 估计后反演（CR-RSF / `randomForestSRC` 和 SurvivalBoost / `hazardous`）是否能对**相同原因1条件分位数**给出可比较预测？哪一种在严格内点时误差更小？本轮只回答“能否规范跑通和首轮量级”，不宣称胜出。

## 设计冻结

- **一次运行**：3 种机制 `aligned`,`cause_tradeoff`,`time_varying`，2 档随机独立删失率（目标 20%、45%），每格 1 个训练/测试配对重复，种子 `20261123`；6 个场景。小样本试跑，后续扩重复不改本次原始文件。
- `Z1~U(-1,1)`, `Z2~Bern(.5)`, A 随机 0/1。训练每场景 **400** 名患者，测试 **120** 名患者，测试对每人预测两个治疗共 240 个处置对象。所有方法同用这些患者与原生 CSV。
- 真 DGP 直接采用 **N1 的解析分段原因别事件强度**，`L=3`，时间切点 `s=1.2`，三机制参数见 `../N1_oracle/src/n1_oracle_study.py`。该事件率是**生成机制**而非 Cox 估计。
- 原生观测：潜在首次事件时间 T 与原因 J，独立指数删失 C；观测 X=min(T,C)，`status=0` 表示删失、`1/2` 表示首次原因。无额外行政删失（只在估值截断到 L），以防把删失和评价窗口混淆。删失率根据固定 DGP 的独立确定性积分校准，不依赖测试真值或某模型胜负。`time` 均为**无临床含义的抽象单位**。
- 统一**诊断**水平 `p∈{0.06,0.12,0.18,0.24}`，刻意包括较高 p 的不可达情形；不是旧论文的固定政策水平，也不是临床认可阈值。
- 统一测试估计对象 `Q1(p|a,z)=inf{t:F1^a(t|z)≥p}`。同一原因1、同一 p、同一测试 (a,z)。`Qall` 是后续扩展，目前不以其成功与否剥夺原因1方法的公平比较。

## 原生候选实现及约束

1. **Peng–Fine**：R 包 `cmprskQR::crrQR`（CRAN 0.9.3），在原观测 `ftime`, `fstatus`, X（包含 `a,z1,z2,a*z1`）上拟合 `failcode=1,cencode=0,variance=FALSE`，通过原包 `predict.crrQR` 得到原因1 CIF 后在 L 内反演。**不是**上轮自写平滑 GMM 原型。若原包不收敛或依赖未安装，记录失败和完整日志，不能静默替代。
2. **CR-RSF**：R 包 `randomForestSRC::rfsrc(Surv(ftime,fstatus)~a+z1+z2+az1,...)`, competing-risk `cif` 输出；`ntree=100` 用于首轮通路验证（不是正式调优最优数）。
3. **SurvivalBoost**：Python 包 `hazardous.SurvivalBoost`，在同样 `(X,status)` 上拟合，并在共同 301 时点的 `[0,3]` 网格预测 CIF；`n_iter` 等使用**冻结的小型 smoke 配置**，记录实际包版本、时间、错误。

方法间差异必须在**同一个**原因1条件 CIF 分位数目标、同一 L、同一 p 与同一测试样本上度量。对 R 预测输出按方法文档解析 CIF 索引，若格式不确定宁可报验证失败。不同包的默认超参是首轮调用核验，不构成“公平超参数优化”。

## 评价与缺失处理

每方法/场景/p 的 `true_both_interior` 样本比例，严格内点时的分位数绝对误差（MAE），`predicted_reachable` 比例，真实不可达却报有限根、真实可达却未报有限根的比例，拟合失败率。若没有真内点且预测有限，不计算伪 MAE；所有缺失、失败和不可比都入结果文件，不能只报成功的条件 MAE。治疗排序仅次要诊断，结果不用于选 p。

本轮主输出是 CSV 表格和失败日志；无结果前不写“某方法更好”。如果三原生包无法在执行环境安装，生成/核验原始数据、真值、分析代码并记录阻碍，**不能把任意替代算法标为原生方法**。

## Go / No-Go

- Go：至少一条原生方法完成 fit + predict + 原因 CIF 维度核验，原始训练与 Oracle 真值数据可复现；其他方法完整呈现安装/拟合状态。
- 完整三方法估计误差排名的前置门槛：三者都实际成功运行、每个场景一致的参数输出，且后续有足够 Monte Carlo 重复和同等程度的调优。一次小试跑**不评优劣**。
- 不加入可达性门控、拒绝治疗、置信选择器或 Cox 回归。
