## GitHub Actions 原生 SurvivalBoost（已实测）

- Python GitHub runner 安装原生 `hazardous==0.2.0`；6 次 fit+predict **6/6 成功**，失败记录为空。
- `n_iter=40`, `min_samples_leaf=20`, `max_leaf_nodes=7`, `learning_rate=0.05`，固定用于 smoke，并非调优最优参数。
- 统一主指标为原因1严格内点的条件分位数 MAE；每个数均仅在真值与预测均有限的可比较记录上计算，同时报告人数及漏报、错报。
