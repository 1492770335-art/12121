# N2-S2：原生竞争风险条件分位数估计——样本量、机制正确设定与配对重复实验

**状态：实验前冻结协议。** 提交本文件后才开始生成本轮数据、拟合与计算；不可根据结果更换阈值、样本量或模型版本。 
**学术主线：比较条件原因别 CIF 分位数估计方法的准确性与稳定性。**
此前 N1、N2-Pilot、N2-2/N2-3 的门控及回退研究均仅作历史经验，**不**参与本轮主方法评比。上一轮 N2-R1 四重复证据偏向 Peng–Fine，但不具备选定赢家的推断力度，且部分方法只在自己的可评分人群计 MAE。本轮直接修复这两项缺口。

## 目标统计量

设两类互斥首次事件 `J=1,2` 和潜在首次事件时间 `T^a`。
[
F_j^{(a)}(t|z)=P(T^a\le t,J^a=j|Z=z),\quad
F_{all}^{(a)}=F_1^{(a)}+F_2^{(a)},\quad
Q_e^{(a)}(p|z)=\inf\{t\in[0,L]:F_e^{(a)}(t|z)\ge p\}.
]
研究重点是 `Q1`（重点原因 CIF 条件分位数），同时必须研究 `Qall`（总体首次事件条件分位数）。当风险水平未在 L 内达到时，用 `NA` 标记不存在的**有限内点分位数**，不将 L 当成发生时点。尚不研究任何第一层筛选、时间损失容忍量、拒绝决策或临床最优风险水平。估计不是 Cox 模型。

## 预先固定实验空间

- **训练规模** `ntrain in {500,1000,2000}`；**4 种机制**：沿用 N1 独立研究三机制 `aligned,cause_tradeoff,time_varying`；再增加 `logquantile_correct` 作为 **Peng–Fine log-time 条件分位数线性设定成立的正向校准对照**。这个“正确设定”机制是公允性诊断，不能把它的性能纳入宣称某方法普遍获胜的主要三机制总评。
- **两档目标独立删失**：20%、45%；**每格配对独立重复**：3 次（`rep=0,1,2`），共 `3×4×2×3=72` 份训练样本。每机制×规模×重复生成同一组 `ntest=180` 个独立测试协变量，复用到两个删失档；各测试人预测两治疗（360 个治疗—人记录）。
- **种子**：`BASE_SEED=2026112305`。时间范围 `L=3` 抽象单位；在前三机制保留 N1 切点 1.2；所有方法在同一对 `Z1~U(-1,1),Z2~Bern(.5)` 与治疗随机化数据上拟合。
- 正确设定机制：`T^a=scale(a,z)*W`, `W~Weibull(k=1.4, scale=1)`, `log(scale)=-0.5+0.15z1+0.12z2+a*(-0.25+0.20z1)`; 给定 T 的原因 J 独立于 T,Z,A、`P(J=1)=0.55`，故 `F_1^a(t|z)=0.55[1-exp(-(t/scale(a,z))^{1.4})]`、`F_all^a(t|z)=1-exp(-(t/scale(a,z))^{1.4})`。于是对任意可达 p，`log Q_1^a(p|z)` 与 `log Q_all^a(p|z)` **关于 (a,z1,z2,a*z1) 线性**，符合 Peng–Fine 的分位数回归函数形式。此机制**并不保证所有数值/删失模型正确**，仅检验量化函数结构。
- `p1=[0.06,0.12,0.18,0.24]`、`pall=[0.15,0.25,0.35,0.45]` 都是诊断网格，不是旧论文“50%、10%、3个月”，不选择某个胜出的 p 作为主分析；可达端点和分位数差异各独立报告。
- 新一轮 DGP 的终点真值由解析 CIF 和逆函数生成，数值验算、三状态概率守恒、数据文件哈希在模型拟合**之前**完成。没有行政截断的 X 生成；预测窗口 L 独立处理。

## 原生方法与冻结训练配置

沿用 N2-R1 源码中已核验的原生调用接口，不能以自写的旧 GMM 代替：
1. **Peng–Fine** R `cmprskQR::crrQR`：输入 `log(X)`、状态，直接预测各治疗、各患者、各 p 的条件原因 CIF 时间分位数；总体首次事件需用 `fstatus>0` 重新编码为唯一原因事件拟合；检查源代码的预测矩阵最后一列为 tau、其他列为预测时间。指定 `tau.range` 与 p 网格匹配，不能在看到测试结果后外推/改变设置。
2. **CR-RSF** R `randomForestSRC::rfsrc`：一次模型对两原因输出竞争风险 CIF（森林参数 `ntree=160,nodesize=15,nsplit=5`）；总体 `F_all=F_1+F_2`，同一规则反演。
3. **SurvivalBoost** Python `hazardous.SurvivalBoost`：同一数据，冻结 `n_iter=55,learning_rate=.05,max_leaf_nodes=7,min_samples_leaf=20`，共同 301 节点时间网格 `[0,L]`；总体 CIF 相加后反演。

**公平性限定**：本轮是各方法**统一冻结配置下的可复现样本量比较**，不是跨方法“最优调参”的比较。Peng–Fine 是直接半参数分位数模型，而森林与提升法模型灵活度高但样本数和迭代预算不同。本轮禁止用测试数据调参；后续可独立设计**训练内交叉验证调参**，不把本轮固定参数结果称为最公平超参数最优排名。所有方法共享相同数据、p、Oracle 真值和独立评价。

## 主要评价和禁忌

- 逐患者—治疗—p 输出 `method,mechanism,n_train,rep,censor,endpoint,p,patient_id,a,true_q,pred_q,true_reachable,pred_reachable`，真实分位数内点才定义有限 MAE，缺失/失败完整保存。
- **第一主结果**：Q1 条件分位数绝对误差；**第二主结果**：Qall 条件分位数绝对误差；两者按每机制、删失、n、p 详细报告。
- 在三方法**共同可评分**的同患者—治疗—p 上计算**配对 MAE**；同时报告每方法可评分率、真可达预测缺失数、真不可达有限预测数，防止以少预测降低 MAE。
- 辅助：`Q1^1-Q1^0` 的分位数差 MAE、严格内点治疗排序错率；只检验分位数估计对排序的影响，不研究门控/拒绝/两层策略。
- 每格独立重复单位是**拟合训练样本**，不是大量相关患者；3 重复只提供初步误差方向和 Monte Carlo SD，**不进行显著优劣推断**。保留每个失败以及耗时，不按可预测值筛选重复。
- 正确设定机制与三个一般机制分表；方法排名不得只在适合某方法的机制下计算。
- 若 Actions 运行时间或依赖问题阻碍全部 72 组执行，报告**完整计划、完成的场景与未完成的场景**，禁止填充/捏造未运行数值。
