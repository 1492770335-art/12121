# 03｜N1 首个正式研究任务：风险水平可达性与治疗排序翻转地图

**研究状态**：已启动 N1 的方法学设计和计算工具；**尚未对新研究数据开展正式实证/模拟比较**。  
**估计器**：N1 不拟合任何生存模型；如果输入是已知真 CIF，那么属于 Oracle/数学性质研究，不涉及 Cox 或其他估计器。  
**固定风险水平**：当前没有；所有数值 p 仅作为**完整诊断网格**的坐标，不是临床最优点。  
**时间窗 L**：应由新研究的目标应用和数据支持事先确定，不自动继承旧项目。

## 0. N1 要解决什么？

三个可以直接由竞争风险 CIF 曲线回答的统计问题：

1. 哪些概率水平 p 在所观察/管理窗口内对**两种治疗的目标原因**和**总体首次事件**都严格可达？这一集合如何随着患者特征变化？
2. 给定患者 z，当 p 改变时两治疗的原因别 CIF 反演排序是否翻转？翻转位于曲线的什么交叉区域？有多少翻转只是端点截断/不可达造成？
3. 如果研究者仍考虑“先保护总体再优化重点”的规则，用**总体 CIF 分位数、RMET 或固定时点竞争原因风险**分别保护会产生怎样的可行集？N1 **不**以某个算法胜出率挑保护对象。

## 1. 两组需要分开报告的量

**统计对象组 A（指标本身）**：
\[
c_j(p;L)=P_Z\{\min_a F_j^a(L\mid Z)>p\},\quad
c_{\rm all}(p;L)=P_Z\{\min_aF_{\rm all}^a(L\mid Z)>p\}.
\]
这里 c 是两治疗均严格内点可达的患者比例，越接近 1 代表在更大比例人群中有充分窗口内支持。**与定量化的删失识别支持是不同问题**。

**统计对象组 B（真实治疗排序）**：
\[
D_1(p,z)=Q_1^1(p\mid z)-Q_1^0(p\mid z).
\]
只在两治疗严格可达且局部分位数有定义的患者中比较正负号；平局、不可达和数值不稳定分别标记，不应把“一个治疗 p 不可达”硬计作无限分位数获胜。

在一个**完整、公开、事先定义的诊断 p 网格**上记录以下信息：覆盖率 \`c_1(p)\`、\`c_all(p)\`、条件排序方向 \`sign(D_1)\` 的人群比例，以及随 p 发生严格内点符号翻转的患者比例。诊断网格不是阈值的优化器，不根据样本结果挑选最有利 p。

## 2. 数据契约与方法学中立的计算脚本

见 \`src/risk_level_audit.py\`。程序读取一个 \`.npz\` 文件：
- \`time\`：严格递增的一维非负时间网格，长度 K，\`time[0]=0\`；
- \`f1\`、\`f2\`：形状为 \`(N,2,K)\` 的真实或模型预测 **原因别 CIF**；
- 每行患者、第二轴为治疗 0/1、第三轴为时间；
- 必须满足每种治疗 \`F1(t),F2(t)\` 单调不减、\`F1+F2≤1\`、初始概率约 0。

该脚本**不是估计器**；它只能审查输入曲线的风险支持。若输入来自估计模型，输出是该模型的预测支持诊断，不是事实真值。

命令（仓库根目录）：

\`\`\`bash
python new_project/competing_risk_quantile/src/risk_level_audit.py --input path/to/cif_truth.npz --output path/to/n1-output --grid-size 199
python new_project/competing_risk_quantile/src/risk_level_audit.py --self-test
\`\`\`

\`grid-size\` 只是数值扫描分辨率，程序在 0–1 上均匀扫描，不设任何固定临床主风险水平；任何未来主 p 与 δ 必须独立于这一次最终测试结果确定。程序输出：
- \`risk_level_support.csv\`：每个风险 p 下两治疗重点、总体都严格可达的比例及重点真值排序比例；
- \`summary.json\`：输入规模、概率/时间合法性诊断、严格内点 p 扫描中有排序翻转的比例；后者对**网格分辨率**敏感，只作探索性指标。

**严禁**将这些探索性数值当作发现新治疗策略临床收益的证据。

## 3. 后续正式 DGP 的中立性要求

初步数据可以使用历史 Oracle 的真实 CIF 作**程序核验和现象复查**，但不可把旧参数视为新课题的已选概率水平。正式研究应另设通用 DGP，允许：
- 无交叉/同向效应：应存在无翻转的阴性机制；
- 部分异质性与原因构成变化：允许、但不强行指定具体方法必胜；
- 时间变治疗效应：用于检验真实 CIF 曲线在不同时间是否交叉；
- 删失：N1 的 Oracle 分析不加入删失；删失下的直接分位数学习属于 N2。

所有参数在查看政策胜负之前冻结，DGP 的校准目标应是现实风险幅度与可识别的随访支持，而不是“使本方法与对照改判率最大”。

## 4. N1 后才进行的三个决策

**决策 A：固定 estimand**。在逐患者条件原因 CIF 时间和政策边际分位数两者之间确认主要学术目标；如果后者为主，需要另行进行因果政策分布识别。

**决策 B：固定风险水平的选择规则**。若是具体临床研究，从患者/临床成本效用出发预设主 p；若没有此类证据，就把整段 p 范围作为**数学机制研究**，不标称临床最优阈值。应用型研究的主 p 只能从训练/独立校准数据及先验偏好确定，不能在最终测试组回看胜负。

**决策 C：确定非 Cox 估计器**。优先从 Peng–Fine 直接 IPCW 方程 vs 联合三状态 IPCW 适当损失学习选择研究主线，在同一目标分布下审查 p 达到内点、删失支持及 CIF 联合合法性。若选择 policy-marginal quantile，需独立引入 Wang/Lei–Qu/Xia 路线，不得混合 estimand。

## 5. 第一轮验收标准与停止条件

- 通过概率合法性、单调性、两原因可相容和严格内点标记的单元测试；
- p-grid 全面呈现，不以最高翻转率挑主 p，明确空可达区域；
- 重点与总体可达率、不同 p 的分位数排序/翻转、协变量异质性有完整数据；若因无输入而未运行，明确标注“协议/工具已建、结果未生成”；
- 临床风险水平没有直接证据时，停止“寻找能让 Q–Q 获胜的 p”；转为报告可达区间和适用边界；
- 阈值数值、估计器、第一层约束未确定之前，不进入大规模完整策略胜负实验。
