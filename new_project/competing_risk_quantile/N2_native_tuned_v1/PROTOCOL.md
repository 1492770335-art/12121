# N2-T1｜竞争风险条件分位数原生估计器：训练内调参与非线性错设实验

**预先冻结日期：2026-11-23。** 本文件在本轮代码、数据生成和拟合之前提交。独立新课题，不采用旧硕士论文的 Cox–Breslow、固定风险水平、共同时间校准和容忍量。**研究主问题始终是分位数估计：比较 Peng–Fine、CR-RSF、SurvivalBoost。**

## 历史事实与本轮要解决的缺口
- N1 发现分位数排序可能随 p 翻转，未得出任何估计器排名。
- N2-R1、N2-S2 已在 GitHub Actions 运行正式原生方法，Peng–Fine 在所选低维三机制的冻结配置下 MAE 较小，但 N2-S2 每格只有 3 次重复，且未进行公平的训练内调参。
- N2-Pilot 的自写 IPCW GMM 不是 Peng–Fine，N2-2/3 的拒绝治疗、可达性门控及回退方案均不进入本轮。
- 此次**不据前轮结果调参数以追求 Peng–Fine 胜出**；保留能支持与不支持直接分位数法的结果。

## 冻结主实验
1. **共同估计对象**：给定基线 z、治疗 a，对两类互斥首次事件定义
[
F_1^a(t|z)=P(T^a\le t,J^a=1|Z=z),\quad
F_{all}^a(t|z)=F_1^a(t|z)+F_2^a(t|z),\quad
Q_e^a(p|z)=\inf\{t\le L:F_e^a(t|z)\ge p\}, e\in\{1,all\}.
]
当窗口内风险不足时，有限内点 Q 不存在，真值及不可估计均记 NA；不能用 L 充作真实内点。
2. **五种机制**：N1 的 `aligned`、`cause_tradeoff`、`time_varying`；N2-S2 的 `logquantile_correct`（独立报告、不混入一般机制平均）；新机制 `nonlinear_interaction`（非线性治疗×协变量、时变风险、两竞争原因，解析分段常风险可积分与反演）。新机制只为检验模型错设及灵活估计器边界，不能依据结果修改生成系数。
3. **数据**：训练 `n∈{500,1000}`，每机制×n×目标删失 `20%,45%`×**4 个独立重复**，合计 **80 份训练样本**；每机制×n×重复独立测试 `Ntest=180` 人，同患者两种治疗共 360 个真值。两档删失共享样本潜在 T/J/Z、仅删失不同。种子 `2026112351`；观察研究窗 `L=3` 抽象时间单位，原 N1 分段切点 `s=1.2`。
4. **诊断分位点（不是临床规定）**：重点 `p1={.06,.12,.18,.24}`；总体 `pall={.15,.25,.35,.45}`。先冻结共同 p，再运行。**不**把旧论文 50%/10%/3 个月当本课题主参数。
5. **输入冻结**：拟合之前生成所有训练/Oracle CSV，解析验证 `S+F1+F2=1`、分位数反演、单调性；保存每份文件 SHA-256。在 GitHub Actions 原生 R/Python 任务中使用同一份上传 artifact，严禁两个任务各自重抽。
6. **预定样本拓展**：本轮先以 n=500、1000 和 4 重复核验训练内调参是否改变此前结论；n=2000 及更多重复只能作为另一次预先冻结的拓展，不在本轮看见差异后补加有利样本。

## 方法及训练内候选集合（所有方法同一个风险时间目标）
- **Peng–Fine（原生 R `cmprskQR::crrQR`）**：输入原始观测 `log(X)` 与状态，正确解析 `predict.crrQR` 的 tau 和时间，分别拟合 Q1、Qall。比较两种**预设**设计矩阵：基础 `(a,z1,z2,a z1)` vs 增加 `z1²,a z1²`（不称其非参数）。原生 `rearrangement=TRUE`，预测仅限窗口内。
- **CR-RSF（原生 R `randomForestSRC::rfsrc`）**：`ntree=160,nsplit=5`，`nodesize∈{5,20}`。同一森林预测两原因 CIF，Qall=F1+F2 后反演。
- **SurvivalBoost（官方 Python `hazardous.SurvivalBoost`）**：`n_iter∈{40,100}`，固定 `learning_rate=.05,max_leaf_nodes=7,min_samples_leaf=20`，301 点等距时间网格 [0,3]；分别反演 Q1/Qall。
- 对每份训练数据按 **预先确定 75%/25% 分层比例的固定伪随机拆分**。候选均只在 75% 子集训练，用剩余 25% 测试**删失校正的截断原因时间分位数 check loss**，随后将评分更优候选在全训练集重拟合；绝不使用 Oracle 测试真值调参。
- 验证目标构造：对指定原因 e 定义 `Y_e=T` 若首个事件为 e 且 T<L，否则 `Y_e=L`；总体 `Y_all=min(T,L)`。只给可观察到 `Y_e` 的记录计权：观察到 L 前首次事件的权重 `1/G_C(T|A,Z)`、生存或删失至 L 后观测的权重 `1/G_C(L|A,Z)`；L 前删失的记录未知而排除。此处生成机制删失独立于 A,Z，`G_C` 使用**训练子集**的 Kaplan–Meier 删失分布估计。三方法使用相同的 p、两终点与权重，评分 `wρ_p(Y_e−min(Qhat,L))` 平均并等权合并。若模型某 p 无有限 Q，评分时对**截断的验证目标**取 `Qhat=L`；但外部估计 MAE 中仍记 NA。此设计防止使用不可达真值做超参选择，且不会开发拒绝治疗方法。
- Peng–Fine 可对 Q1/Qall 分别选设计；Forest/Boost 一个共同 CIF 模型选超参。实际有效候选不足或程序失败均记录并报告，不得换成自写算法。

## 公平评价和停止准则
- **第一主表**：真正三方法在**同一真实严格内点且三方法都有有限预测**的患者×治疗×p 上的 Q1 条件分位数 MAE。**第二主表**：Qall 条件分位数 MAE。
- 必须并列报告：各方法自有可评分率、三方法共同可评分率、真可达漏报／不可达误报、原生拟合失败率、验证损失、实际被选超参、模型运行时间。不可通过只输出更少预测而降低 MAE。
- 辅助：两治疗 Q1 分位数差的 MAE、排序错误率。**不**开展总体保护规则、治疗回退、拒绝推荐或临床疗效优效证明。
- 比较配对差以**独立训练重复**为 MC 单位，四次重复仅属扩展 pilot；不给论文级显著性推断。
- 正确设定控制 `logquantile_correct` **单独报告**，不把它混入包含非线性机制的一般机制汇总以人为改变排名。
- 若 R 或 Python 原生方法未实际运行，必须停在完成阶段并明确说明，不能套用先前实验的 MAE。
