# N2-H1 Oracle 重点事件条件分位数排序异质性（估计前独立诊断）

本表从 **72 份冻结数据中的 24 份独立 Oracle 测试集**得到。每个机制有训练规模 500/1000 × 四个测试重复 × 每测试集 180 位患者，即 1,440 人；两删失档共享 Oracle 患者，**不能重复计入分母**。

对固定患者的治疗 0/1，计算预定 `p1 = {.06,.12,.18,.24}` 下真条件分位数 `Q1^1(p|z)-Q1^0(p|z)`。只有双方均有严格有限分位数、差的绝对值大于 1e-9 时才计入对应 p 的严格比较。若同一患者至少两个可比较 p 的差出现相反符号，则记“方向翻转”。

| 机制 | 分位数排序翻转人数 | 总人数 | 翻转比例 |
|---|---:|---:|---:|
| hd_correct（log-Q 线性正向控制） | 0 | 1440 | 0.00% |
| hd_nonlinear（八维非线性交互） | 66 | 1440 | 4.58% |
| hd_crossing（八维时变交叉） | 150 | 1440 | 10.42% |

**解释**：这是由真实 DGP 解析 CIF 反演的 Oracle 性质，不包含任何拟合估计器、更没有治疗策略优效。说明实验能产生分位数目标随 p 变化的条件排序问题；仍以 Q1、Qall 的真实条件分位数估计精度为主实验。
