# N2-H1｜高维非线性与时变错设下的条件 CIF 分位数估计器比较

**预注册冻结日期：2026-11-23**。本文件必须先于 N2-H1 的数据生成和新方法拟合提交。本轮为独立新课题，主线仅是**竞争风险中条件原因别 CIF 分位数的估计**，不使用旧硕士论文的 Cox 估计、临床阈值或治疗回退策略。既有 N2-T2 的八重复结果单独保留，**不修改**。

## 1 研究问题
比较真正的原生实现 Peng–Fine \`cmprskQR::crrQR\`（直接条件分位数回归）、CR-RSF \`randomForestSRC::rfsrc\`（CIF 反演）和 \`hazardous.SurvivalBoost\`（CIF 反演）：在八个基线协变量、非线性交互、风险随时间交叉的条件下，谁能更好恢复
\[
Q_j^{a}(p\mid z)=\inf\{t\in[0,L]:F_j^{a}(t\mid z)\ge p\},\quad 
Q_{\rm all}^a(p\mid z)=\inf\{t\in[0,L]:F_1^a(t\mid z)+F_2^a(t\mid z)\ge p\}.
\]
若目标 CIF 到 L 仍未达 p，**不存在窗口内严格有限分位数**，记缺失 NA；不把 L 当作真实 Q。统一 L=3 抽象单位、分段风险切点 s=1.2，绝不赋予诊断 p 临床含义。

## 2 新数据生成机制（预先固定，不看估计结果调系数）
每名患者 \`z1 ~ Uniform(-1,1)\`, \`z2 ~ Bernoulli(.5)\`; \`z3..z8 iid Uniform(-1,1)\`，共**8 个基础协变量**；治疗 A 独立 Bernoulli(.5)。条件两原因的分段常数原因别风险 \`r[a,j,k]\`，k=0 for t≤1.2、k=1 for t>1.2；因此完整 CIF 和真实 Q 可**解析求解**（N1 oracle）。这些风险率仅用于**生成真值**，不是 Cox 估计方法。以下中心化 \`u4=z4²-1/3\`, \`h=sin(pi*z3*z5)\`：

- \`hd_correct\` **独立控制**：总体时间 \`T=scale(a,z)*W\`，\`W~Weibull(shape=1.4, scale=1)\`，原因 J 与 T 独立且 \`Pr(J=1)=.55\`。\`log scale= -0.5 +.15z1 +.12z2 +.10z3-.08z4+.07z5+.08z6-.07z7+.06z8 + a*(-.25+.20z1+.15z3)\`。因此 log Q1、log Qall 在所有 p 的内部支持上均关于基础设计线性。此组只验证已知正确模型结构，不参与下面两种复杂机制的主平均。
- \`hd_nonlinear\`：以 N1 \`cause_tradeoff\` 的正风险率为基础。对控制及治疗两组的两个时间段分别将原因1风险乘 \`exp(.25*z3+.20*u4+.15*z7)\`，原因2乘 \`exp(-.20*z3+.20*z6-.15*z8)\`。**仅治疗1**四类风险的附加乘子 \`(cause1 early, cause1 late, cause2 early, cause2 late)\` 依次是 \`exp(.75*h+.45*u4+.25*z6*z7)\`, \`exp(-.55*h+.35*z7*z8)\`, \`exp(-.60*h-.35*z3*z6)\`, \`exp(.45*h+.30*u4)\`。其方向是按协变量异质性规定，而非为了让某方法在测试中获胜。
- \`hd_crossing\`：以 N1 \`time_varying\` 为基础。对控制及治疗共同的原因1乘 \`exp(.22*z3+.15*z5*z6)\`，原因2乘 \`exp(-.20*z4+.17*z7)\`。**仅治疗1**四类风险的附加乘子依次 \`exp(.8*h+.45*z4*z6)\`, \`exp(-.9*h+.45*z7*z8)\`, \`exp(-.65*h+.35*z6*z7)\`, \`exp(.8*h-.40*z5*z8)\`。该机制故意包含同一患者的治疗效应随时间反向，但**不**保证任意选定 p 下会改判；Oracle 可达率及排序特征必须如实报告。

所有风险率保持正值，并以 CIF \`F1+F2+S=1\` 验证；观察数据 \`X=min(T,C)\`, \`status=0/1/2\`, 指数独立删失 C 的强度仅由预先校准的 DGP 边际目标 20%/45% 确定。

## 3 试验规模与可复现性
- \`n_train ∈ {500,1000}\`; 每机制×训练规模×删失目标 20%/45%×**4 个独立训练重复**，合计 **48 份训练 CSV**；每机制×n×rep 共享一份独立 \`n_test=180\`、两治疗 360 个记录的 Oracle 测试 CSV，合计 **24 份 Oracle CSV**。
- 固定全新随机种子 \`BASE_SEED=2026112371\`；同一机制/规模/重复的两档删失使用相同潜在 T/J/Z 和测试患者，只改变 C；所有方法读取同一组数据且在拟合前逐文件核对 SHA256。新任务必须与 N2-T2 旧文件隔离。
- 在两种终点上使用同一历史冻结**诊断 p**：\`q1=[.06,.12,.18,.24]\`，\`qall=[.15,.25,.35,.45]\`；不可为了模型胜负改 p。
- 本轮**不是**≥50 重复的正式推断，四重复仅为高维压力试验兼容性验证与粗略比较；不能把全部患者或所有 p 作为独立重复夸大精度。

## 4 原生估计器、训练内调参和错误记录
所有方法训练/验证共享预先随机 75%/25% 拆分；独立删失用训练子集 Kaplan–Meier 得 \`G_C\`；在未使用 Oracle 真值的留出样本上，采用既有 \`validation_score.py\` 的原因时间截断 \`Y_j = T if J=j and T<L else L\` 和统一 IPCW pinball loss，给不同候选同等评价，再在完整训练数据重拟合。真实原因是2时重点分位数伪时间为 L，遵守竞争事件语义。
- **Peng–Fine**：原生 \`cmprskQR::crrQR\`，时间输入 \`log(X)\`；两套模型设计：基本 \`[a,z1,z2,...,z8,a*z1,a*z3]\`；扩展在基本上再添加 \`z3*z5,a*z3*z5,z4²,a*z4²,z7*z8\`。预测时原包返回患者的**分位数时间**，预测矩阵最后一列为 tau；q1 / qall 原生分别拟合（总体 status 把两原因合并），窗口内无根记 NA。
- **CR-RSF**：原生 \`randomForestSRC::rfsrc\` 的 \`ntree=160, nsplit=5\`，\`nodesize in {5,20}\`；输入同一基础八维协变量、治疗及其两个交互（从两原因 CIF 反演 Q1 与 Qall）。
- **SurvivalBoost**：原生 \`hazardous.SurvivalBoost\` \`n_iter in {40,100}\`，固定 \`learning_rate=.05,max_leaf_nodes=7,min_samples_leaf=20\`；预测 [0,3] 301 节点网格两原因 CIF 再反演。模型默认时间零概率、单调性问题均如实标记。
- 本轮冻结训练内两个候选而非充分调参：**不宣称完全同计算预算最优配置**。如果原生模型失败或无预测，必须保留记录，不能重新抽样、改 seed 或用自写原型冒称原生方法。

## 5 主评价与交付
- **第一主结果 Q1**：固定同一患者/治疗/p、**三个方法共同可评分、真值严格有限内点**下的 MAE。**第二主结果 Qall**：同法计算。机制、删失、n、p、重复分开报，再按**两种复杂机制等权**宏平均；正确设定控制另表。
- 同时报告三方法各自可评分率、拟合成功/失败、真可达漏报、真不可达误报、不同 p 与删失的误差、选中的候选参数、估计计算耗时。为避免共同评分选择偏差，必须单列错误分类/覆盖度。
- 辅助检验两治疗 \`Q1^1-Q1^0\` 差的 MAE 与符号错误，仅检验条件分位数估计的效果，不构造任何完整治疗推荐方法。
- 每次**训练重复**才是配对 MCSE 的独立单位；4重复只供探索。输出原生逐患者预测，R/Python 运行日志、源代码、冻结数据哈希、配对结果 CSV 和带负面结果的统计评审。
