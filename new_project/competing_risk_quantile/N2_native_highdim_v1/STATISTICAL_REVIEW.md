# N2-H1｜八维竞争风险条件分位数估计器高维压力试验——统计评审

**研究主题**：在竞争风险与右删失下，比较真实发表的 Peng–Fine 直接条件 CIF 分位数回归、CR-RSF CIF反演和 SurvivalBoost CIF反演对给定患者与固定治疗的 Q1 和 Qall 的估计精度；非 Cox 拟合，不属于旧硕士论文，也不研究回退治疗。

## 1. 实验及证据链

- [真实 GitHub Actions #45213043665](https://github.com/1492770335-art/12121/actions/runs/45213043665) 的 frozen-data、6 个原生 R、6 个原生 Python 和 combine 均成功；全部 144 次原生**全样本模型拟合**成功。
- GitHub 已自动提交全部原始逐患者预测与重复级结果；我另行下载 12 份原生分片 artifact，在本地**独立拼接并复算**，与 CI 的 138,240 条 Oracle 记录、134,557 条共同可评分记录及各组 MAE 完全一致。
- 第一次 workflow 在 CI 与本地CSV不同字节哈希时停止于**拟合之前**，无错误估计器结果；第二次把CI数据仅生成一次、固定哈希并共享 artifact，不改变机制、p、seed 或方法超参。具体见 [ORACLE_AUDIT.md](ORACLE_AUDIT.md)。

- 原始方案早于数据生成和原生拟合提交：[PROTOCOL.md](PROTOCOL.md)，commit `9de4c9e6`。
- 三机制：8维对数分位数正确设定控制 `hd_correct`；高维非线性 `hd_nonlinear`；高维时变交叉 `hd_crossing`。正确设定控制不纳入一般复杂机制主平均。
- n=500/1000、目标删失20%/45%、每格4次独立训练重复；48份训练CSV、24份独立Oracle测试，p1=.06/.12/.18/.24，pall=.15/.25/.35/.45，L=3抽象时间单位。
- 数据在 GitHub Actions 的唯一 frozen-data job 中生成并冻结 SHA256，再由原生R/Python同批读取；本地文本序列化与CI哈希可能不逐字节相等。
- 所有方法先按统一的训练内 75/25 拆分使用删失加权分位数 pinball loss 选候选，再全量拟合。
- 主指标是三法**同患者、同治疗、同p且真值严格内点**的 MAE，未估计出有限 Q 的记录不得用L代替；漏报、误报和失败另计。

## 5. 直接分位数估计与森林反演的配对差

下表的平均差为 **Peng–Fine MAE 减 CR-RSF MAE**，正值表示 CR-RSF 较小。对于同一个机制×n×终点，先在每个独立训练重复内对两删失档和四个预设诊断 p 的**同患者误差差**等权平均，然后按四个训练重复计算 MCSE。

| 机制 | n | 终点 | 平均配对差 | MCSE |
|---|---:|---|---:|---:|
| hd_nonlinear | 500 | Q1 | +0.0706 | 0.0232 |
| hd_nonlinear | 500 | Qall | +0.0570 | 0.0144 |
| hd_crossing | 500 | Q1 | +0.0567 | 0.0148 |
| hd_crossing | 500 | Qall | +0.0897 | 0.0190 |
| hd_nonlinear | 1000 | Q1 | −0.0145 | 0.0212 |
| hd_nonlinear | 1000 | Qall | +0.0490 | 0.0100 |
| hd_crossing | 1000 | Q1 | +0.0272 | 0.0187 |
| hd_crossing | 1000 | Qall | +0.0019 | 0.0063 |

**结论边界**：n=500 的两个复杂机制中，森林对 Q1 和 Qall 的配对 MAE 都较小；但 n=1000 时这种优势减弱或在 Q1 非线性机制中逆转。每格仅四次独立训练重复，仍不能据此宣称置信区间意义上的普遍优效。

值得注意，正向控制 `hd_correct` 虽然在理论上令 **log 条件分位数对设定协变量线性**，Peng–Fine 在 n=500 的 Q1 MAE 仍为 0.0679，CR-RSF 为 0.0469；n=1000 分别为 0.0451 和 0.0375。这不意味着对数分位数真模型被误设，而提示“模型函数形式正确”也不自动保证**有限样本估计误差最小**。直接法的误差可能涉及数值求解、删失和高维参数估计等因素，但**本轮没有对偏差与方差作固定测试对象的严谨分解**，不可武断归因。

## 6. 统计解释与后续定位

本轮是 **四重复、冻结候选集的高维压力试验**，不应把哪一方法 MAE 较小解释为所有竞争风险 DGP 的普遍优势，也不是经过完整超参预算公平性的最终赢家。高维场景用正向控制和强错设两类独立表评价，保留模型失败和真实风险水平不可达的病例。

如果某个方法在复杂机制下更优，它说明估计函数类与数据风险结构的匹配价值，不等于已构成新的算法创新。下一轮应再做训练规模和足量重复验证，明确估计偏差/方差以及性能边界。

原始CSV和完整逐患者预测/训练内选参日志均保留，可根据相同 Oracle 数据独立复算。
