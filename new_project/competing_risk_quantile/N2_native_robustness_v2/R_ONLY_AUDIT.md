# N2-T2｜原生 Peng–Fine vs CR-RSF 的中间结果（非三方法最终评审）

**数据来源**：GitHub Actions [#45197296031](https://github.com/1492770335-art/12121/actions/runs/45197296031) 三个独立 R 原生分片；已下载并读取真正的 `native_r_predictions.csv` 与 `native_r_fit_status.csv`，不从旧 N2-T1 结果抄数。**待 SurvivalBoost 完成后，正式主表必须重新限制到三方法共同可评分患者，不可将本两方法数值直接放入三方法排名。**

本文件严格只针对**原生 R 两方法**，并只评价竞争风险条件分位数的估计精度。

- 3 机制×12 个独立训练重复×2 目标删失档，共72套右删失训练资料；每套同患者 Q1/Qall 各4个诊断 p。
- 原生 `cmprskQR::crrQR`（Q1/Qall）最终训练状态 72/72 成功；原生 `randomForestSRC::rfsrc` 最终训练状态 72/72 成功。
- 两方法各输出 207,360 条患者×治疗×p 预测，共 414,720 条原生结果；两方法**同患者且真值有限可评分** 206,947 条。**本轮所用诊断 p 的 Oracle 真值全为内点。**
- Peng–Fine 的设计选择：linear 50、quad 22；森林 nodesize 20 选70次，nodesize 5选2次。来自训练内验证，不接触 Oracle。
