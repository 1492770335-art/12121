- 冻结协议先提交 `1fe90f8252ea5fe49687d20afc312e0fe1121ab7`，随后用独立种子 `2026112361` 生成数据；
- 五机制×n∈{500,1000}×八重复×两删失档：160 份训练CSV；机制×n×八重复：80份独立测试CSV，**合计240份CSV**。

- 本地 numpy 2.3.5 / scipy 1.17.0 / pandas 2.2.3 重放验证，240份CSV哈希均匹配本地 `FROZEN_SHA256.json`。第一次 GitHub runner 重新生成的浮点CSV与本地字节哈希有差异，因此 runner **不使用本地哈希作为原生模型拟合门槛**；改成在同一次 `frozen-data` job 一次生成和冻结 runner 原生 `data/manifest.json`，并以**同一个已上传的不可变 artifact**提供后续全部估计器读取。每个拟合job从该artifact下载数据并以其中的manifest逐文件复核SHA256。最终combine拟保存runner真实manifest到 `results/CI_FROZEN_SHA256.json`。两个环境的CSV序列化是否逐字节相同，不影响所有三种原生模型**在runner内共享同一份数据**，不允许谎称与本地字节相同。
- Oracle (S+F_1+F_2=1) 及有限分位数反演的解析核验通过。
- 本地真值账本：230400条机制×n×重复×删失×患者×治疗×分位点记录，**229515条真实严格内点分位数**，其余885条未达；有限真值比例约99.616%。不是模型预测可评分率。
