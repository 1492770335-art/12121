## 5. 后续分析决策（建议，未执行）
1. 定义同一移植前时点的强度选择；总体首次失效是复发或NRM，不是OS；两层选择不是两次给药。重点事件NRM（J=1），竞争复发（J=2）。
2. 原因别模型 λ_j(t|a,z)=λ_0j(t)exp[β_j^T z+α_j a+γ_j a×DRI]；预设有临床依据的年龄/KPS/HCT-CI治疗交互，避免仅按显著性筛选；针对两种疾病编码和中心聚类。若供者信息并非决策前可得，应另做不含供者的明确目标模型。MRD、细胞遗传详细类别、合并症细节不可用，条件可交换性不保证；两种治疗不一定对每人均临床可行。
3. 由两原因累积危险率联合构造 S、F_NRM、F_rel，保证 S+F_NRM+F_rel=1；反演共同p,q阈值。36月截断与不可达指标分别存储；检查条件阈值附近斜率及支持，报告两治疗均达、单侧达、均未达。训练内校准不能用测试结局。
4. 以中心分组交叉验证，比较样本外两原因CIF及DFS校准（6/12/24/36月），记录PH、重叠、分位数可达率。只有通过后才冻结估计器、p,q与容忍量。
5. 主要研究问题是相同患者上不同完整规则是否给出不同推荐，而非证明本方法在自己优化的指标上必然更优。报告各方法RIC/NMA推荐率、逐患者改判率、按DRI/年龄/体能分层的改判，以及两种分位数的条件值配对比较；观察实际治疗分配作描述性参照，不冒充因果效果。RMET不作为必要主指标；期末两原因CIF用于解释竞争风险机制。分清平均条件分位数与政策边际分位数。尚未完成条件分位数反演、规则比较或独立因果评价。
