## 重要结论

1. **原因别 Cox → CIF → 分位数**：方法在模型正确时合法；但 Cox 的 PH/共享基线假设可以失效，反演在低密度的风险阈值附近可能不稳定。
2. **Peng–Fine 2009 已直接估计原因别 CIF 分位数**：本轮通过用户资料库内完整原刊核验，模型不局限于指数连接函数，表1/表2已查到。此方法不能自动给出本文整个总体约束+重点择优策略。
3. **其余多篇研究的是人群边际策略分位数**，与本文逐患者条件原因别 CIF 分位数有本质不同；Linn 的 two-stage 指两次真实给药，并非本文同一时点的两层选择。
4. 当前最科学的主实验应**先固定决策，替换估计器**，然后**固定估计器，替换决策准则**，最后做各方法完整端到端比较。
5. 在竞争风险中，更晚达到原因 1 CIF 阈值可能由更高原因 2 风险引起，所以必须同时报告两原因期末 CIF、总体首次事件时间和 RMET。
