# EXP-02：总体分位数保护与 RMET 保护的定向 Oracle 比较

## 研究对象与可复现性

本研究固定真实竞争风险分布、重点事件目标 (Q_{1,0.10,36}) 和两阶段决策顺序，只比较第一层以总体分位数 (Q_{all,0.50,36}) 或 36 月无首次事件限制平均时间 (R=int_0^{36}S_{all}(t)dt) 保护患者的后果。总体分位数规则允许最多损失 3 个月；RMET 规则的绝对预算由独立 100,000 人校准样本匹配“双治疗都合格”的比例，`PH_tradeoff` 为 **1.353642** 月，`time_cross` 为 **1.217904** 月。两规则随后在合格治疗中最大化同一个重点分位数。对 `PH_tradeoff` 和 `time_cross`，各重建原实验的 200 个测试重复，每次 5,000 人；没有估计模型或改动风险参数。

原始 ZIP 的 SHA-256 为 `4700ea52b9a50c0d96786965ad4fe13e30b0b40952292bc396700699c34a06b7`。归档不含逐患者记录，故用其中的原生 `src/oracle.py`、`config.json` 和固定随机数索引定向重建。每一重复的旧规则改判人数，以及重点分位数、总体分位数、RMET、36 月两原因 CIF 的配对均值，均与归档 `pairs_raw.csv` 在 (10^{-10}) 内一致。重新汇总的改判率为 **2.5106%** 和 **2.0974%**，对应统计评审四舍五入后的 2.511% 和 2.097%。两机制的重点分位数严格平局数均为零；统一平局策略与原实现的推荐逐人一致。以下数值均为 Q–Q 减 RMET–Q1。

## 第一层保护如何改变候选治疗

独立校准使两规则的总体双候选比例相近，却不保证候选集合由相同患者构成。`PH_tradeoff` 的候选集合不一致率为 2.5106%，且每次不一致都改变最终推荐。`time_cross` 的候选集合不一致率为 4.7342%，其中 2.0974% 改变推荐；其余患者仍选择共同合格且重点分位数较高的治疗。两个机制都没有“双规则各只允许一种、且所允许治疗相反”的患者。任何改判均包含第一层候选集合差异。

`PH_tradeoff` 的 12,254 名 Q 推荐 1、R 推荐 0 的患者，Q 增加重点分位数 **15.4173** 月，却减少总体分位数 **2.8450** 月和 RMET **1.4363** 月；36 月重点 CIF 下降 **20.0902** 个百分点，竞争 CIF 上升 **25.1420** 个百分点。另 12,852 名 Q 推荐 0、R 推荐 1 的患者，Q 增加总体分位数 **3.1919** 月与 RMET **1.2698** 月，重点分位数反而缩短 **18.0595** 月；重点 CIF36 上升 **18.6173** 个百分点、竞争 CIF36 下降 **23.4643** 个百分点。两方向大致相抵，形成表 B 的小幅全体均值；不能用全体均值掩盖个体层面的风险原因取舍。

`time_cross` 的 9,565 名 Q 推荐 1、R 推荐 0 的患者获得 **0.3102** 月重点分位数差，同时总体分位数下降 **2.8684** 月、RMET 下降 **1.3037** 月；重点 CIF12/36 却分别增加 **7.6444/22.5714** 个百分点，竞争 CIF12/36 下降 **6.1327/14.4354** 个百分点。另 11,409 名 Q 推荐 0、R 推荐 1 的患者总体分位数增加 **3.1856** 月、RMET 增加 **0.9204** 月、重点 CIF36 下降 **18.7092** 个百分点，但重点分位数缩短 **0.0448** 月。前一组说明早期风险阈值的到达时间可以与 36 月重点事件发生概率反向变化；[改判者联合分布](figures/changed_joint_outcomes.png) 同时展示两指标，不把 CIF 分位数差说成实际事件时间的平均延迟。

Q–Q 对自身的逐人总体分位数预算没有违反。以相同 3 月 Q 预算评价 RMET–Q1，`PH_tradeoff` 与 `time_cross` 分别有 **1.2852%**、**1.1409%** 的测试记录超出预算；超出者的平均超额分别为 **0.1919**、**0.1856** 月。反过来，Q–Q 超出各自 RMET 预算的比例为 **1.2254%**、**0.9565%**。这两类超额率针对不同保护量，不能直接解释为同一临床损失。两规则各自约束均由 Oracle 构造满足。

## 统计判断

**总体 Q 保护提供什么信息？** 它限制每名患者的总体 CIF 达到 50% 所需时间相对最佳治疗的损失不超过 3 个月。RMET 是整段生存曲线下的面积，能够在总体分位数跨过该时间阈值时仍判定治疗合格。本实验在双候选总体比例经过独立匹配后，仍找到 2.5106%/4.7342% 的候选成员差异；这验证两种保护量并不等价。完整总体 CIF 曲线同时包含分位数与 RMET 的计算信息，差别在决策泛函和预设患者偏好。

**哪些患者需要，收益与代价如何？** 差异集中于 `Z1` 的两个局部区间和两个保护预算的边界。全部分位数严格内点，端点截断不能解释这些改判。`PH_tradeoff` 的两种改判方向带来幅度很大的相反重点与竞争事件风险变化；净平均重点分位数对 Q–Q 为负。`time_cross` 改判者虽平均多得 0.1171 月重点分位数和 0.4247 月总体分位数，却少得 0.0939 月 RMET，12 月重点 CIF 增加 0.6355 个百分点。其方向之一还出现重点分位数增加与 36 月重点 CIF 大幅增加并存。总体风险代价需要由事先明确的风险阈值偏好评价，不能由分位数自身判为可接受。

**能否据此维持论文第一层总体 Q 的优越性主张？** 当前证据支持其作为一种明确定义的逐人时间阈值保护准则，并支持说明在何种患者中它与 RMET 保护不同；**不足以支持它在临床结局上普遍优于 RMET 保护，也不足以证明第一层必须选总体 Q**。两机制的全体结局差很小；改判者的重点事件、竞争事件和 RMET 互有代价。论文可继续采用总体 Q 作为与预先规定的“50% 总体风险阈值时间最多损失 3 月”偏好相符的研究对象，但应将贡献表述为该偏好的个体化决策边界，而非无条件临床净收益。Oracle 结果也不涉及有限样本估计精度。

## 数值与解释边界

原始归档的三个数值测试及 EXP-02 的四个一致性测试全部通过。检查包括 CIF 单调与 (F_1+F_2=F_{all})、分位数和 RMET 落在 0～36 月、候选非空、规则自身预算、改判包含于候选不一致、全体差的分解，以及逐重复对原结果的重放。患者记录在同一重复中配对，共用冻结的真实风险分布；MCSE 衡量有限次 Monte Carlo 积分误差，不能当作临床试验置信区间。均值是测试协变量分布下**条件截断分位数的平均**，不是政策诱导总体的边际分位数，也不是实际事件时间平均延迟。两机制之外的外部 Zhou 指数情景在本次未补算，其截断上限问题仍按原统计评审解释。
